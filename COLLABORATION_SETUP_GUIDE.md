# 🚀 Smart AI Timetable Generator — Setup & Collaboration Guide

This project is configured with a **Shared Supabase Cloud PostgreSQL Database**, meaning **both you and your teammate can work on this project from different laptops simultaneously**. Any leaves applied, faculty added, or timetables generated by either person will be saved directly in the shared cloud database!

---

## ⚡ Quick 1-Click Start (Windows)

Simply double-click:
👉 **`start_all.bat`**

This script will automatically:
1. Install any missing packages for backend & frontend (`npm install`).
2. Launch the backend API server on **Port 5000**.
3. Launch the frontend React interface on **Port 3000**.
4. Open **http://localhost:3000** in your default browser.

---

## 🛠️ Manual Terminal Start

If you prefer using the terminal or VS Code / Antigravity IDE:

### 1. Install Dependencies
```bash
# In the project root directory:
npm install

# In the frontend directory:
cd frontend
npm install
cd ..
```

### 2. Run Backend & Frontend

**Terminal 1 (Backend API):**
```bash
node backend/server.js
```
*API runs at:* `http://localhost:5000/api`

**Terminal 2 (Frontend React App):**
```bash
cd frontend
npm run dev
```
*Web App runs at:* `http://localhost:3000`
